# Локальная текстовая модель

Используется предобученная [cointegrated/rubert-tiny2](https://huggingface.co/cointegrated/rubert-tiny2), MIT, русский язык, 312 измерений, CLS pooling + L2. ONNX-экспорт: [iki13/rubert-tiny2-onnx](https://huggingface.co/iki13/rubert-tiny2-onnx/tree/5e6f7f225ff590999fc409e3e747c382d79d94b5). SHA-256 ONNX: `39dcd6f039c9dfa269795259cec99ca85c75a2002ba72efe186b8068a8d7ad03`; словаря: `f056a69b097422652053bf87565c35543e5d81540ca4b7dddd28de4157a969e0`.

Перед сборкой: `pwsh -File scripts/download-model.ps1` (Windows) или `sh scripts/download-model.sh` (Linux). Скрипт скачивает только веса и словарь из фиксированной ревизии, проверяет хеши, не исполняет код модели. Файлы в models исключены из Git. Docker скачивает их при сборке; готовый комплект включает их рядом с JAR. NEXUS_MODEL_DIR переопределяет каталог.

Java использует [ONNX Runtime CPU](https://onnxruntime.ai/docs/get-started/with-java.html), без облачного API и Python. Токенизация: cased BERT WordPiece, NFC, очистка control/format, разделение пробелов/пунктуации/китайских символов. Текст разбивается на последовательные блоки до 254 токенов + CLS/SEP. Нормализованные CLS-векторы блоков усредняются с весом числа токенов и снова нормализуются. Вектор пользователя — нормализованное среднее векторов всех его личных рассказов. Ранжирование по косинусному сходству; при равенстве — userId.

Это использование готовой NLP-модели; на пользователях её не дообучаем. Сходство текста не является вероятностью успешных отношений, проверкой достоверности или психологической оценкой. CV, анализ внешности и collaborative filtering в этой версии отсутствуют. Личные тексты, векторы и названия рассказов не возвращаются другим участникам; публичные темы и подпись редактируются отдельно.
