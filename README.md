# Nexus Backend

Backend-часть проекта **Nexus**, обеспечивающая обработку запросов, бизнес-логику и работу с данными.

## 📌 Описание

Серверная часть отвечает за:
- Предоставление REST API
- Аутентификацию, авторизацию и управление пользователями
- Управление профилями и их настройками
- Обработку пользовательских взаимодействий
- Формирование персонализированных рекомендаций
- Безопасное хранение и получение данных

## 🛠 Технологии

- **Язык программирования:** Java
- **Фреймворк:** Spring Boot
- **Безопасность:** Spring Security
- **Работа с данными:** Spring Data JPA, Hibernate
- **База данных:** PostgreSQL

## 🏗 Архитектура приложения

Проект построен по слоистой архитектуре (Layered Architecture):

- **Controller** — обработка HTTP-запросов и REST API
- **Service** — реализация бизнес-логики приложения
- **Repository** — взаимодействие с базой данных через Spring Data JPA
- **Entity** — сущности базы данных
- **DTO (Data Transfer Object)** — объекты для передачи данных между слоями и клиентом
