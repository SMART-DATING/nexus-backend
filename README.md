# Nexus Backend

Backend-часть проекта **Nexus**, обеспечивающая обработку запросов, бизнес-логику и работу с данными.

## 📌 Описание

Серверная часть отвечает за:
- Обработку HTTP-запросов клиента
- Реализацию бизнес-логики приложения
- Взаимодействие с базой данных
- Управление пользователями и аутентификацию
- Алгоритмы формирования рекомендаций

## 🛠 Технологии

- **Framework:** ASP.NET Core
- **ORM:** Entity Framework Core
- **Database:** PostgreSQL

## 🏗 Архитектура

Проект построен по принципам многослойной архитектуры (Clean Architecture):

```text
├── API             # Обработка HTTP-запросов и контроллеры
├── Application     # Бизнес-логика, сценарии использования и DTO
├── Domain          # Доменная модель (основные сущности и интерфейсы)
└── Infrastructure  # Взаимодействие с базами данных и внешними сервисами
